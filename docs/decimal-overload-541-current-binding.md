## What “truthful” must mean at an inherited entry

For the conditional arithmetic argument, start with valid immutable stored coefficient/scale state and a valid context. Every **actually reached** virtual leaf must deliver its required value, coefficient/scale/encoding, sign/precision and specified exception/identity behavior, as applicable. Returned objects are included transitively whenever the next source operation examines them. Returning an equal numeric value at a forbidden scale, a wrong byte encoding or a fabricated quotient is not made truthful by delegating only signum/precision. Conversely, an unrelated unused poisoned getter does not remove an inherited method’s independent public mathematics.

This is a graph premise on the particular entry and reached leaves, not a runtime-class restriction or blanket invalid-subclass waiver. Fresh own base wrappers used by581/590 and private raw bridges have a simpler stored-state graph; ordinary construction normalizes a coefficient subtype through its reached byte encoding, while current-own-format restoration can retain a truthful coefficient subtype. The580/583/585/592 and pending594 proofs explicitly account for that route. Accepted legacy-stream exclusion does not exclude current-own restored objects.

Three distinct obligations must not be conflated:

1. A directly selected caller override gets the original arguments and returns/throws the caller’s supplied result/exception with its required identity. An explicit caller `super.f` selects the superclass body at that call site. All reviewed37 declarations remain overridable in their Kotlin class surface; the accepted inheritance/language contract is parametric, not an obligation to duplicate every possible caller class in tests.
2. Within the current body, a written virtual call has ordinary language dispatch. Source reasoning/tests can record that it reaches an override. An alternative mathematically correct implementation is not thereby required to use that same internal recipe, number/order of callbacks, equal instance, runtime class or noncall. Direct explicit caller behavior and internal implementation choice remain separate.
3. A base inherited result must satisfy its mathematical/cohort/error/canonical/identity laws under its stated valid reached premises. Current storage-based certification cannot be excused from a wrong result just because some unused method elsewhere is poisoned. A claim of a true mandatory failure needs the exact entry, stored representation, reached leaves and violated clause; a single global label such as “delegate mode” is insufficient.
