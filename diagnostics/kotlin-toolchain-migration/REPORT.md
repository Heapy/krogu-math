# Kotlin Toolchain migration verification

This migration replaces the active Gradle build with Kotlin Toolchain 0.13.0,
Kotlin 2.4.21 and JDK 25. It retains all eleven library targets and the existing
Maven coordinates. Historical diagnostics describe their original toolchains;
they are not new Kotlin Toolchain measurements.

## Local functional verification

| Area | Observed result | Scope |
| --- | --- | --- |
| Source relocation | 331 original files byte-identical | Production, tests, Java callers and resources |
| JVM | 700 tests passed, then two optional diagnostic methods passed separately | Aggregate 702 original methods; JUnit 4 includes Java tests |
| JS / Node 24.16.0 | 468 original tests passed; corrected new worker fixture passed separately | Aggregate evidence, not one 469-test run |
| Wasm / Node 24.16.0 | 469 tests passed in one run | Includes actual embedded-worker execution |
| macOS ARM64 Native | 474 tests passed in one run | Host runtime only |
| Worker closure validation | Three unit tests passed | Includes rejection of nested/incomplete closure layouts |
| Oracle scripts | All 25 commands have successful executions | Initial batch passed 23; checks 1 and 18 were rerun with CI's required `JAVA_TOOL_OPTIONS=-XX:-OmitStackTraceInFastThrow` |

Initial linkage, registration, stale-cache and invocation failures were retained
in the local verification workspace. No failed run is counted as a pass.
KTC 0.13.0 test-link workarounds supply main-library friend paths and disable
test compiler caches where required. Native paths are generated by the ignored,
first-party bootstrap; production source visibility and assertions are unchanged.
The Node runner rejects zero discovered tests.

## Publication compatibility

An isolated raw publication produced the root and all eleven target modules.
The first-party compatibility assembler preserves `krogu-math-wasm-js`, rewrites
the complete Maven graph consistently, and adds the generated worker getter
exactly once to each web source JAR. The independent output review checked 420
files, 52 variants and 25 redirects. Runtime artifacts remain byte-identical to
the compiler output, and no private worker module is published.

A separate Maven consumer resolved all eleven targets, including the explicit
historical Wasm coordinate. Public integer, parallel and decimal smoke checks ran
on JVM, JS, Wasm and macOS ARM64. Normal publication mode also completed into a
fresh local destination. These results do not imply runtime execution on all
eleven targets or publication to an external release repository.

## Evidence and reproduction

The adjacent receipts retain independent source, publication, consumer and
benchmark findings. Paths inside them identify the original local verification
workspace, not a promise that ignored files are part of this delivery. Current
commands are in the root README and benchmarks README. Historical numerical
campaigns and their immutable archives are unchanged.

After successful local runs, an exceptional cleanup fence was added so failure
to enumerate process descendants cannot prevent termination of the known parent.
It changes no measurement, test or compiler arguments; earlier execution receipts
retain their original source hashes. Hosted validation must bind the final
migration commit. Hosted Compatibility and public-large results are pending at
this pre-push checkpoint.
