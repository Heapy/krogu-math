## Public API and semantic selection gates

**IonsPin:** [tagged public README](https://github.com/ionspin/kotlin-multiplatform-bignum/blob/0.3.10/README.md) documents BigInteger parseString/fromLong, arithmetic, divrem, radix text and two’s-complement byte helpers. Its integer `not()` is explicitly different from Java’s infinite two’s-complement operation. Decimal parseString/fromLong/explicit-operation DecimalMode and scientific/expanded output are documented. DecimalMode combines precision, rounding and scale; defaults, mode inheritance and quotient scale differ from JDK. Wasm is described as experimental with Float-conversion caveats. These are real arbitrary-precision decimal operations, but not a blanket java.math compatibility claim.

**Kt-math:** [tagged README](https://github.com/gciatto/kt-math/blob/0.10.2/README.md) identifies a Kotlin port of BigInteger/BigDecimal/java.math. This supports peer selection, not proof of every JDK25 overload, exception, preferred cohort or newer API. Public generated API pages attempted at gciatto.gitlab.io/kt-math returned403 and gciatto.github.io/kt-math returned404. Therefore exact adapter signatures and per-operation coverage remain **unverified**; do not fill them from implementation source or assume current JDK25 parity from the project description.

**KBigNum:** [tagged public README](https://github.com/gatrongdev/kbignum/blob/v0.0.20/README.md) documents KBigInteger/KBigDecimal, fromString/extensions, arithmetic, signed bitwise behavior, KBigMath and explicit fixed-scale division. Its decimal `/` defaults to scale10/HALF_UP; use the documented divide(other,scale,rounding) when comparing fixed-scale work. A significant-digit MathContext-equivalent API is **unverified**. The README broadly advertises JS/Native, but the exact published0.0.20 metadata above is narrower. Its published benchmark tables are author observations, not Krogu same-host evidence and are not reused as timing results.
